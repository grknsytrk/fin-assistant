# CV Bullets (Fin-Rag Case Study)

- React ve FastAPI tabanlı, yapılandırılmış finansal veri uygulaması geliştirdim; BIST, KAP ve TEFAS verilerini tek bir arayüzde birleştirdim.
- KAP snapshot/cache akışıyla finansal tabloları, bildirimleri ve şirket bazlı overview verilerini hızlı ve tekrarlanabilir şekilde sundum.
- TEFAS fon listesi, geçmiş fiyat/getiri verisi ve tarihsel portföy dağılımını SQLite/cache katmanıyla frontend'e taşıdım.
- API sözleşmelerini ve eski route uyumluluğunu koruyarak RAG/embedding bağımlılıklarını üretim akışından çıkardım.
